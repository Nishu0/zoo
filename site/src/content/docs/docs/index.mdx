Zoo gives AI agents their own computers: Linux, macOS or Windows desktops, browsers and
shells, each in its own [microVM](/docs/concepts/runtimes/). Agents drive them over
MCP, REST or a Python SDK. You watch, and take over when needed, from the dashboard.

Everything runs on your hardware. One command installs the whole stack on a single
Ubuntu or Debian host.

<CardGrid stagger>
  <Card title="Install">
    One command on a fresh Ubuntu or Debian server, with or without KVM.
  </Card>
  <Card title="Your first sandbox">
    Create a desktop, browser or code sandbox in the dashboard and drive it.
  </Card>
  <Card title="Connect Claude Code or Claude Desktop">
    Point any MCP client at Zoo and it gets every sandbox tool.
  </Card>
  <Card title="Policies">

  </Card>
</CardGrid>
